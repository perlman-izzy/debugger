# Cloud bootstrap objective

Incrementally strengthen the isolated deterministic prototype for validated long-horizon coding.

Immediate scope:
- model VERIFIED_FACT / HYPOTHESIS / FALSIFIED_HYPOTHESIS / UNKNOWN distinctly;
- executor output cannot authorize acceptance;
- ACCEPT / REJECT / INCONCLUSIVE remain distinct;
- transient retry, implementation retry, epistemic reset, and trajectory reset remain distinct;
- after two independent rejections of the same causal hypothesis for the same subgoal, ordinary implementation retry is forbidden and an epistemic reset is required;
- reset packets contain verified facts, accepted checkpoint identity, and falsified hypotheses, but not executor narrative as authoritative truth;
- add adversarial tests for attempts to bypass these invariants.

This cloud branch is a prospective prototype only. Do not claim integration with the local OCC/job-agent-lab/DSH system.
